Online perception experiment · jsPsych 8

Do happy words make grey look brighter?

Participants read a word, then judge whether a grey square is brighter or darker than a reference. In the main block every square is physically identical — so any systematic difference between positive and negative words is the mind, not the monitor.

The study

  1. Practice — six trials whose squares really are brighter or darker, with feedback; repeated automatically if accuracy is low.
  2. Main block — 74 words (positive, negative, neutral), all followed by the reference grey. A cover task (press Space when a word repeats) keeps attention on the words.
  3. Valence ratings — participants rate each word, a manipulation check on the categories.
  4. Debrief — the reveal, plus a personal results dashboard computed in the browser.

Under the hood

Frame-timed custom plugin

Fixation, word and probe run as one requestAnimationFrame-scheduled trial. Actual on-screen durations are measured and saved with every row.

Reproducible randomisation

Each session is seeded and the seed is stored, so any participant's exact trial order can be regenerated. Pass ?seed=… to fix it.

Signal-detection scoring

The cover task is scored as hits vs. false alarms with a corrected d′, instead of a raw percentage.

Built-in simulation

jsPsych's simulation mode runs a whole virtual participant — visually or data-only — for demos and automated tests.

Local CSV data

No server or third-party upload: data is exported as a CSV in the browser, with unique file names and focus-loss and fullscreen-exit counts for quality control.

No build step

Static files with pinned, integrity-checked CDN dependencies. Unit tests in Node, end-to-end tests in Playwright, run in CI.
