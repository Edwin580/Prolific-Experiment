Do happy words make grey look brighter?

People read a word, then say whether a grey square is brighter or darker than a reference. In the main block every square is the same grey, rgb(168, 168, 168). If positive words still get more “brighter” answers, the difference is in the viewer.

Your display, measured live

Browsers can only change the screen on a frame. A 400 ms word on a 60 Hz monitor is really 24 frames, and one dropped frame stretches it by 17 ms. The custom trial plugin schedules every change on requestAnimationFrame, switches when less than half a frame remains, and saves the measured duration on every row.

How many people would it take?

Pick an effect size and a sample. The simulator runs a thousand virtual studies in your browser. Each participant gets their own bias, answers binomially, and the group is tested with a one sample t test on the positive minus negative difference. Power is the share of studies that reach p < .05.

Effect is the difference in the share of “brighter” answers after positive and negative words. 0.06 means 56% versus 50%, roughly.

04

How it is built

Plain static files, no build step. The analysis code on this page is the same file the study uses at the end of a session, and the same file the unit tests import in Node.

src/plugin-word-probe.js

Custom jsPsych plugin. Fixation, word and square run as one trial on animation frames. The repeat key and the brightness answer are recorded separately, and it supports jsPsych simulation in visual and data modes.

 src/analysis.js

Per category summaries, RT exclusion, and the cover task scored as d′ with the Hautus log linear correction. The inverse normal is Acklam’s approximation, written out by hand.

 src/design.js

Trial order, repeat pairs, break placement that never splits a pair, and collision safe file names. Every session is seeded and the seed is saved, so ?seed= replays an exact order.

 tests/

Node unit tests for the pure logic. Playwright runs whole simulated sessions, real keypresses, consent refusal and the CSV download. CI also checks every CDN script against a pinned version and SRI hash.
